# DeckCompiler Phase 4 Curated Fixture

This directory is the source-controlled curated Phase 4 fixture for the six-slide DeckCompiler demo.

At the Phase 4C boundary it contains semantic/planning artifacts plus one accepted canary:

- six Sidecar-authoritative semantic records;
- one Visual DNA and one neutral Creative Front-End design-system/template-spec wrapper;
- thirteen deterministic platform-image request artifacts;
- a six-record pending Visual Target manifest;
- a capability attestation verified by the canary;
- one selected, verified Design Board under `references/`;
- two attempt seals and execution/verification/visual-review records;
- a regeneration history and Phase 4C validation report.

The rejected first-attempt binary is intentionally absent. Its exact prompt and evidence records are retained without adding to the canonical thirteen-prompt set. Phase 4D may add only accepted Module Anchors, Batch Template References, and six Slide Visual Targets.

The Visual Target is visual truth only. The Semantic Sidecar is the sole authority for exact copy, values, units, data, citations, accessibility text, and native/raster policy. No generated image in this fixture may be used as a final full-slide PPTX or HTML surface.

The runtime source is an isolated directory outside the repository. All paths stored here are relative; the fixture contains no credentials, provider transport, PNGtoPPTX output, PPTX, HTML, render output, or protected `outputs/` artifact.
